# Uber Request Data Analysis

## Project Overview

This project analyzes Uber ride request data to identify demand patterns, cancellation trends, ride completion rates, and vehicle availability issues.

The project was completed using:

* Microsoft Excel
* MySQL
* Python (Pandas, NumPy, Matplotlib)
* Google Colab

---

## Objectives

* Clean and preprocess Uber request data
* Build interactive dashboards in Excel
* Generate business insights using SQL
* Perform Exploratory Data Analysis (EDA) using Python
* Identify peak demand periods and operational bottlenecks

---

## Tools Used

| Tool         | Purpose                   |
| ------------ | ------------------------- |
| Excel        | Data Cleaning & Dashboard |
| MySQL        | Querying & Insights       |
| Python       | EDA                       |
| Google Colab | Analysis Environment      |
| GitHub       | Version Control           |

---

## Key Insights

* Peak ride demand occurs during morning and evening hours.
* Airport requests experience higher "No Cars Available" cases.
* Cancellation rates increase during high-demand periods.
* Trip completion rates vary across pickup locations.
